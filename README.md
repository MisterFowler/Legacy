# Legacy

**An open-source MMORPG built from the ground up in Rust, for Linux.**

Legacy is an independent MMORPG project focused on building a persistent multiplayer world using Rust. The goal is to create an extensible, maintainable game architecture with a dedicated server and a native client.

This is a project built from scratch, with an emphasis on understanding and controlling the entire technology stack rather than relying on an existing MMORPG server emulator.

## Project Goals

Legacy aims to provide:

- **A persistent world:** A shared multiplayer environment where the world and its inhabitants continue to exist beyond an individual player's session.
- **Server authority:** Gameplay state and important game decisions are controlled and validated by the server.
- **Multiplayer:** Players can explore, interact, and participate in the same world.
- **A living world:** NPCs, creatures, merchants, and other inhabitants should make the world feel active and populated.
- **Extensibility:** A modular architecture that allows new gameplay systems, content, and mechanics to be developed over time.
- **Open development:** Source code is available for anyone to study, use, modify, and improve.

## Technology

Legacy is being developed primarily in Rust.

Current development environment:

- **Language:** Rust
- **Build system:** Cargo
- **Server:** Dedicated Rust server
- **Client:** Native Rust client
- **Initial platform target:** Linux
- **Version control:** Git

Additional technologies and dependencies will be documented as the architecture develops.

## Development Status

**Early development — not yet playable.**

The initial focus is establishing the project structure, development environment, server architecture, client architecture, and networking foundations.

Development milestones and technical decisions will be documented as the project progresses.

Expect significant changes during this stage.
